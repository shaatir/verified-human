# Interface components

## Home

- `home-nav`: product identity and immutable demo-environment state.
- `home-hero`: the screening claim, framed as a triage tool rather than identity proof.
- `signal-rail`: three-stage evidence model: observe, challenge, route.
- `cta-card`: a keyboard-accessible button that enters participant or analyst workflows.
- `demo-notice`: visible boundary for simulated data and human-review requirements.

## Analyst workspace

- `profile-btn`: mutually exclusive simulated threat profile selector.
- `telemetry-grid`: compact display of the observable event values.
- `score-summary-card`: routed risk state and score; its rule breakdown remains the explanation.
- `tier-section`: groups evidence by behavioral, semantic, and footprint signal families.
