# UX audit

## Changes applied

- Replaced emoji-led language with a structured security-console hierarchy.
- Changed clickable `div` cards into native buttons for keyboard access.
- Added explicit prototype boundaries to prevent overclaiming from the first screen.
- Reframed the product around reviewable evidence and human decision-making.
- Added visible focus styles for the primary operator controls.

## Remaining product risks

- Scores should not be used to make automated participant decisions without validation and an appeal path.
- The demo would need a backend trust boundary before its client-side telemetry can support an anti-tamper claim.
